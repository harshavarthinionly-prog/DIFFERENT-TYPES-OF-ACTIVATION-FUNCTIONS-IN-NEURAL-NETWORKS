# DIFFERENT-TYPES-OF-ACTIVATION-FUNCTIONS-IN-NEURAL-NETWORKS
Activation functions determine a neuron’s output and introduce non-linearity, enabling neural networks to learn complex patterns. Common types include Sigmoid, Tanh, ReLU, Leaky ReLU, PReLU, ELU, SELU, Softplus, Softsign and Softmax. Each has a specific formula, output range and application.
